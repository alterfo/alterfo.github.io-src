# FinContext MCP — финансовый контекст для AI-ассистента

**Задача.** У бизнеса деньги размазаны по счетам в разных банках и по учётной системе. На вопрос
«сколько у нас реально свободных денег» отвечает бухгалтер через день, а не система.

**Ограничения.** Токены банков нельзя отдавать разработчику. Облако — чужое. Ответ должен быть
проверяемым, а не «модель посчитала».

## Что сделал

MCP-сервер, который подключает ассистента сразу ко всем банкам и учёту и отвечает на живые
вопросы:

- реальный остаток по всем счетам;
- прошёл ли конкретный платёж;
- прогноз кассового разрыва;
- сверка выписки с учётом.

**Модель доверия.** Клиент разворачивает сервер у себя: Terraform в его Yandex Cloud, токены
банков и учёта read-only лежат в его Lockbox. Код открыт для аудита, данные не покидают контур.

**Стек.** Yandex Cloud Functions, API Gateway, YDB, Lockbox, Terraform. Базовые коннекторы —
Точка и МойСклад. Pro-лицензия открывает движок сверки, прогноз, 1С и алерты.

## Доказательство

- Репозиторий: [github.com/alterfo/fincontext-mcp](https://github.com/alterfo/fincontext-mcp)
- Деплой описан пошагово: Terraform-модуль, least-privilege сервисный аккаунт, инструкция для
  MCP-клиента.
- Есть демо-инстанс на демо-данных, без чужих токенов.
