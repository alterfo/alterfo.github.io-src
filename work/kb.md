# kb — база знаний на GraphRAG

**Задача.** Ответить на вопрос по коду, документации, задачам и переписке команды. Не «найти
похожий абзац», а назвать актуальное значение: какая цена, какая версия, какое решение принято
последним.

**Ограничения.** Источники разнородны. Часть фактов устарела, часть противоречит друг другу.
Модель должна не просто достать фрагмент, а понять, что он перекрыт более новым.

## Что сделал

- **Гибридный поиск**: dense + BM25 + RRF. Один retrieval не вытягивает и точные термины, и
  перефразировки.
- **Граф знаний**: узлы-сущности и связи между ними, поиск с учётом графа, а не только векторов.
- **Graph-of-Thoughts**: оркестрация рассуждения по графу вместо одного вызова модели.
- **Временная модель**: строгое вытеснение устаревших фактов и детектор противоречий.
- **Слой верификации**: проверка цитат и конфликтов между источниками.
- **Парсер юридического корпуса** с золотым набором для проверки извлечения.
- **15 коннекторов** и MCP-сервер, чтобы система работала из ассистента, а не из отдельной вкладки.

## Доказательство

Замер на срезе EnterpriseRAG-Bench, 60 вопросов. Каждая ступень добавляет одну возможность.

| Ступень | DCS | stale_leak | miss |
|---|---|---|---|
| dense-only | 0.18 | 0.09 | 0.73 |
| + hybrid | 0.27 | 0.09 | 0.64 |
| + rerank | 0.27 | 0.27 | 0.45 |
| + Graph-of-Thoughts | 0.58 | 0.06 | 0.24 |
| + temporal | 0.61 | 0.15 | 0.15 |

DCS — доля ответов с актуальным значением вместо устаревшего. Промахи упали с 73% до 15%.
Честная оговорка: 11 вопросов в срезе, один вопрос двигает DCS на 0.09. Это паттерн, не рейтинг.

Код и таблица замеров: [github.com/alterfo/kb](https://github.com/alterfo/kb).
